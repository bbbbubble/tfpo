# TFPO explainer composition

Remotion source for the TFPO project-page explainer. The composition uses
large native text, data-driven animation, paper-derived visual inputs, and a
borderless caption track. It contains no TFPO training or evaluation code.

```bash
npm install
npm run dev
npx remotion render TFPOExplainer ../site/public/tfpo-explainer.mp4
```
